# 定义 Definition

**强单点光**指用**一个明确、强度高、方向清晰的光源**照明，让主体一面被照亮、
另一面落入深阴影。它拒绝"均匀补光"——补光会消灭阴影，而阴影才是这个光型的作品本身。

对视觉系而言，单点光承担三个功能：
1. **塑形**——白妆在硬光下显出面具般的立体感与边界
2. **分离**——全黑造型（黑衣+黑发+黑背景）靠光带区分层次
3. **营造舞台感**——单点光天然带有"舞台聚光灯"的叙事暗示

# 视觉特征 Visual Cues

- **光源方向明确**：侧光、前侧光、顶光、或逆光，可一眼判断
- **硬阴影**：阴影边缘相对锐利，不是柔和的渐变
- **暗部深沉**：远离光源的一侧接近全黑
- 常为**高反差比**（亮部与暗部曝光差 3–5 档以上）
- 光源类型可辨：聚光灯、窗户、台灯、闪光灯

# 变体 Variants

- **侧光（side light）**：最经典，塑形最强，一半脸亮一半暗
- **顶光（top light）**：眼窝陷入阴影，制造阴郁/危险感
- **前侧光（45°）**：相对柔和，保留更多信息量
- **逆光/轮廓光（rim/back light）**：从背后勾出边缘，适合黑发黑背景的分离
- **聚光灯（spotlight）**：小范围强光，周围全黑，舞台感最强
- **闪光灯（flash）**：正面硬光，直白、纪实、Y2K 实拍感

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 柔光/影棚平光 | 柔光消除阴影，与本光型目的相反 |
| 高调（high-key）| 高调画面明亮、阴影少；本光型是**低调（low-key）** |
| 多光源布光 | 多光源若做得好也能有对比，但"单一"是关键——多光源容易产生混乱的第二阴影 |

# 生成提示 / 常见失败

- 易失败点：模型默认**均匀柔光**（尤其人物肖像）。必须强调 `single source, harsh, hard shadows, low-key, deep shadow side`
- 全黑造型在弱光下会糊成一团：**务必明确光源方向 + 加入轮廓光**分离轮廓
- 若需在视频中使用，单点光下的缓慢动作（转头、抬头）会产生强烈的光影流动，效果很好
- 负向词建议加：`soft even lighting, flat lighting, multiple light sources, studio softbox, bright ambient light`
