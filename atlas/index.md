# Atlas · 原子图鉴

所有视觉元素的精细分类库。每个元素是一个可自由组合的"积木"，含中文定义与英文 Prompt Keywords。

> **检索建议**：概念页已有 160+，不必逐层读本目录下的 index。
> agent 请优先读自动生成的 [[compact|检索索引]]（按 type 分组的紧凑清单）
> 或 `index/graph.json`（含出链/入链关系）。

## 元素维度
* [[atlas/subject/index|subject/]] — 角色原型、面容肤色、表情、姿态
* [[atlas/hair/index|hair/]] — 发型、挑染（含视觉系尖刺立发、遮眼刘海）
* [[atlas/makeup/index|makeup/]] — 眼妆、唇妆、腮红、水钻、美甲（含视觉系白妆体系）
* [[atlas/wardrobe/index|wardrobe/]] — 上装/下装/外套/套装/鞋履（含黑色修身西装）
* [[atlas/accessories/index|accessories/]] — 首饰、眼镜、包袋、身体装饰、发饰
* [[atlas/setting/index|setting/]] — 场景、道具、场景装饰（含视觉系暗厅舞台）
* [[atlas/color/index|color/]] — 配色方案与色卡（hex）
* [[atlas/material/index|material/]] — 面料与表面材质（含蕾丝/皮革/缎面绒）
* [[atlas/lighting/index|lighting/]] — 光源、光质、光位（含强单点光）
* [[atlas/camera/index|camera/]] — 景别、机位、镜头、构图、画幅
* [[atlas/grade/index|grade/]] — 胶片/DV 质感、颗粒、调色、光晕、后期图形（含高对比戏剧质感）
* [[atlas/motion/index|motion/]] — 运镜、动作、节奏、转场、特效（视频）
* [[atlas/audio/index|audio/]] — 音乐风格、音效
* [[atlas/mood/index|mood/]] — 情绪与审美态度
