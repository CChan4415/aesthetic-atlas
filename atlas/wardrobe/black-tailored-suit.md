# 定义 Definition

**黑色修身西装**是视觉系（尤其 [[visual-kei-kote-kei|Kote-kei]]）的制服级单品。
它之所以成为图腾，是因为它同时满足两个需求：

1. **轮廓**——西装提供**明确的肩线与挺拔的躯干**，让"尖刺发 + 白妆"有了承托的结构
2. **克制**——在一堆华丽元素中，西装是"减法"，让妆容与发型成为绝对焦点

它通常不是普通商务西装：剪裁更修身、下摆更长、细节（立领、蕾丝、绑带、金属扣）被改造。

# 视觉特征 Visual Cues

- **全黑**，面料哑光或半光（羊毛、混纺、偶尔缎面）
- **修身剪裁**：贴合躯干、收腰、明确肩线
- 变体结构：**长下摆**（燕尾/大衣式）、**短款**、**不对称前襟**
- 内搭：黑衬衫、高领、立领、或蕾丝衬衫
- 细节改造：蕾丝拼接、绑带、金属扣、皮质翻领、刺绣
- 下装：修身西裤、或宽腿裤、或配长靴

# 变体 Variants

- **经典修身**：标准两件/三件套，最简洁
- **燕尾/长下摆**：戏剧化，动作时有飞扬感（适合视频）
- **军装式**：立领、肩章、排扣，硬挺（偏 Kote / 军事系）
- **蕾丝拼接**：领口袖口加蕾丝（偏 Angura）
- **皮质改造**：皮领或皮袖（偏 Grunge / Kirakira）
- **无袖马甲式**：露出内搭袖子

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 商务西装 | 关键在于**造型配套**（妆/发/配饰）与剪裁极端度；孤立看容易太普通 |
| 洛丽塔/哥特裙装 | 那是裙装体系；西装是裤装/中性体系 |
| 单纯穿黑衣 | 需要剪裁的锐利感与配套造型才成立 |

# 生成提示 / 常见失败

- 易失败点：模型默认生成**宽松商务西装**（尤其"西装"一词）。需强调 **slim fit, sharp shoulders, tailored, long tailcoat**
- 与"白妆+尖刺发"组合时，画面信息量很大，建议用**中景或半身**，避免全身导致细节丢失
- 若需视频使用，长下摆与开襟设计能产生布料动态，**优先选择长下摆变体**
