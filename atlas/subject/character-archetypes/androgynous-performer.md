# 定义 Definition

**性别模糊表演者**指**刻意不指向单一性别**的角色形象。它不是"中性风"的简化版，
而是一种主动的美学策略：同时呈现两种性别的特征，让观者无法归类，
从而产生**"非日常"与"被吸引但无法定义"**的张力。

这是 [[visual-kei|Visual Kei]] 的核心主体原型——视觉系从诞生起就以
"男性化轮廓 + 女性化妆饰"的雌雄莫辨为标志。它同样出现在 1990s–2000s 的高级时装影像中
（见 [[david-lachapelle|David LaChapelle]] 等摄影师的作品）。

# 视觉特征 Visual Cues

## 面部
- **明确的骨相**（颧骨、下颌线）与**精致的五官**（大眼、小脸）并存
- 妆容同时具备"锐利"与"精致"——重眼妆 + 干净的轮廓
- 性别特征被刻意调和：不用极端的阳刚或柔美处理

## 身体与姿态
- 纤细修长、比例偏瘦长
- 姿态优雅但有力，避免过度的"柔"或"刚"
- 常出现中性化的手势：抚发、抬手、托腮

## 造型
- 服装跨越性别边界：西装、蕾丝、束腰、长外套
- 妆造强度高（视觉系的标志）
- 发型男性化（短发、尖刺）或女性化（长发、卷发）都可，重点在**与面部特征的错位**

# 变体 Variants

- **锐利系**：偏男性轮廓 + 重妆，攻击性强（Kote-kei 常见）
- **精致系**：偏中性柔和，美貌主导
- **华美系**：偏女性化 + 男性骨架，视觉系 Angura 常见
- **少年系**：年轻、单薄、介于少年与少女之间（Oshare-kei 常见）

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 中性风 / 无性别风 | "中性"常指简约克制的日常穿着；本原型强调**精致的妆造与强烈的美学意图** |
| 男扮女装 / 女扮男装 | 那是"扮演另一个性别"；本原型是**同时呈现两者**，不指向任何一方 |
| 单纯"长相好看" | 关键在**性别特征的刻意调和**——必须有可辨识的双向特征 |

# 生成提示 / 常见失败

- 易失败点：模型会**默认归入某一性别**并强化该性别的典型特征。需强调
  `androgynous, gender-ambiguous, neither clearly male nor female`
- 建议同时描述"男性骨架"与"精致五官"，双向拉扯比单说 androgynous 更有效
- 若生成结果偏向一端，可加入另一端的具体特征（如"sharp jawline"配"soft full lips"）
- 负向词建议加：`hyper-masculine, hyper-feminine, bearded, overly muscular`
