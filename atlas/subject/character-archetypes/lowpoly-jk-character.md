# 定义 Definition

**低多边形 JK 角色**是 2000s PS1/PS2 游戏与同人 CG 中的日本女高中生（JK）3D 模型原型。
与真人偶像、2D 动漫角色、当代写实 3D 都不同——它是**特定硬件限制下的 3D 少女形象**：
块状三角面头发、贴图绘制的眼睛和嘴、单色或简单渐变的皮肤、合并的方块手。

> **核心魅力**：这种"技术不足"反而产生独特美感——它**不是真人**（不会产生恐怖谷），
> **不是 2D 动漫**（有体积与光影），而是介于两者之间的"虚拟人偶"。

# 视觉特征 Visual Cues

## 头部与脸
- **头发**：块状三角面发片、有明显几何边缘、长直发或麻花辫最常见、
  刘海可能是单块三角形、发丝不会动（除非 vertex wobble）
- **脸**：贴图绘制的眼睛（大而低分辨率）、眉毛、嘴；面部几何简单，下颌线柔软
- **肤色**：单色 / 双色渐变、无毛孔、可能有腮红贴图（脸颊两侧粉色块）

## 服装（JK 制服典型）
- **上衣**：白色衬衫 + 米色或深色针织开衫 / 西装外套
- **领结**：黑色或红色蝴蝶结 / 领带
- **下装**：格子百褶裙（红灰/蓝灰格纹）
- **袜子**：及膝袜（白/黑）或泡泡袜
- **鞋**：乐福鞋（棕/黑）或厚底鞋

## 身体
- **手**：常合并为方块手或简单棱柱手指
- **比例**：6–7 头身，腿偏长（日式动漫比例）
- **动作**：略僵硬（手 keyframe 动画感）

# 变体 Variants

- **PS1 级低模**：头发只有几个大块、眼睛贴图非常粗糙、皮肤单色
- **PS2 级低模**：头发更细、眼睛贴图更精细、皮肤有渐变
- **MMD 级精细低模**：接近动漫 3D（《Vocaloid》MMD 风格），皮肤光滑、贴图高清

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| **真人 JK** | 真人是摄影；本元素是 3D 渲染（看头发是否块状三角面） |
| **2D 动漫 JK** | 2D 是绘画；本元素是 3D（有光影体积） |
| **当代写实 3D 角色** | 那是高模+SSS；本元素是低模+贴图绘制 |
| **虚拟主播 Live2D** | Live2D 是 2.5D 平面；本元素是真 3D |
| **虚拟主播 3D**（HoloLive 等） | 那是当代精致 3D；本元素是 2000s 硬件限制美学 |

# 生成提示 / 常见失败

> **预判**（待实测验证）：

- **介质锚定词**：`low-poly 3D rendered character, PS2-era game girl, chunky triangle hair, texture-mapped face`
- **必须显式排除写实**：`photorealistic, real human, live action, high-poly sculpt, subsurface scattering`
- **头发要写清**：`blocky triangle hair pieces, chunky low-poly hair`，否则模型会输出丝滑头发
- **眼睛是贴图**：`painted eyes on face texture, no 3D eyeballs`——防止模型建出真实眼球
- **JK 制服细节**：`beige cardigan, white shirt, black bow tie, plaid pleated skirt, knee-high socks, loafers` 全部列出
