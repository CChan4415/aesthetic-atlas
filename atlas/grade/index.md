# Grade · 画面质感 / 调色 / 后期

## Y2K 系（做旧 / 低保真方向）
* [[vhs-dv-texture]] — VHS / DV / Hi8 磁带影像质感
* [[film-grain]] — 胶片颗粒
* [[cross-processing]] — 交叉冲洗 / 偏色褪色
* [[magazine-flash-grade]] — 千禧杂志片调色
* [[lens-flare-haze]] — 光晕 / 柔焦 / 雾化
* [[light-leak]] — 漏光
* [[digital-overlays]] — 时间码 / 贴纸 / 边框 / UI / bounding box / 双语字幕 叠层

## Visual Kei 系（戏剧 / 高对比方向）
* [[high-contrast-grade]] — 高对比戏剧质感（深压黑、去饱和、锐利高光）

## Retro Game CG 系（低模 / 渲染介质方向）
* [[low-poly-3d-render]] — 低多边形 3D 渲染（PS1/PS2 实时渲染的三角面 / 低分辨率贴图 / vertex wobble）
* [[ps2-fmv-grade]] — PS2 FMV 预渲染质感（比实时渲染精细但仍带 2000s CG 痕迹）

## 负向控制元素 Negative Control
* [[anti-modern-digital]] — **去现代数码感**（对抗模型默认输出当代高清照片/当代 3D 渲染的倾向；
  含**摄影介质**与**渲染介质**两类锚定词库与负向词）

> **方向相反，勿混用**：Y2K 做旧追求"像旧录像带"（噪点/褪色/低清）；
> 视觉系高对比追求"像戏剧海报"（干净/极深黑/锐利）；
> Retro Game CG 追求"像 PS1/PS2 游戏截图"（低模/贴图/锯齿）。选一个作主导。
