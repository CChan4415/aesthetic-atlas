# 视觉特征 Visual Cues

- 明显噪点/颗粒、轻微扫描线、色彩偏移（RGB 色差）
- 底部/顶部磁带跟踪条、偶发画面滚动、丢帧
- DV：4:3、锐利中带压缩块；VHS：更软、对比度低、色溢
- 可带红色时间码、REC 标识、电池闪烁

# 强度分级

轻度（仅暖偏色+细颗粒）/ 中度（扫描线+色差）/ 重度（跟踪条+滚动+重度噪点）。
