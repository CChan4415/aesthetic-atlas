# 定义 Definition

**深色烟熏眼**指用深色眼影在**眼窝、眼周甚至延伸到颧骨方向**大面积晕染，
把眼睛周围处理成一片深色阴影区的妆容。与日常烟熏不同，视觉系的版本：

- **面积更大**——不止眼睑，常延伸到眼下与太阳穴
- **颜色更深更"脏"**——黑、炭灰、深紫、暗红、墨绿
- **边界可以不干净**——刻意的晕染与污浊感是效果的一部分
- **与白妆配合**产生极强对比

它替代了"用眼窝阴影制造立体感"的思路，反过来**用深色把眼睛"淹没"**，
制造一种深邃、疲惫、或濒临失控的阴郁美感。

# 视觉特征 Visual Cues

- 深色**大面积包围眼部**，眼窝完全被压暗
- 常见**上下眼睑同时深色**，形成包围式阴影
- 颜色：黑、炭灰、深紫、暗红、酒红、墨绿
- 边缘可柔和晕染，也可保留粗糙边界
- 常叠加亮片/珠光在中心，形成"暗中有光"的层次
- 与白妆配合时，深色区域像在脸上下了一道"伤"

# 变体 Variants

- **黑灰经典**：最通用，冷峻
- **紫调**：深邃、华美，偏 Angura
- **红调**：病态、危险、血液隐喻（偏吸血鬼系）
- **绿调**：异质、怪奇
- **中心亮片**：深色打底 + 眼中亮片，Kirakira 交叉

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 日常烟熏妆 | 日常追求"晕染干净、范围可控"；视觉系可**故意不干净、范围外扩** |
| 黑眼圈/疲态 | 那是生理状态，无结构；烟熏眼是有意识的层次与配色 |
| 单纯涂黑 | 需要**层次**——深色、中间色、提亮点的关系，否则脸会变成一团黑 |

# 生成提示 / 常见失败

- 易失败点：模型容易"清理干净"成一个精致日常眼妆。需强调 **smudged, heavy, large area, sunken**
- 若与白妆同时使用，务必强调对比，否则白妆会被暗色污染成灰调
- 建议指定颜色而非只说 "smoky eye"，避免默认生成棕色系
- 负向词建议加：`clean subtle eyeshadow, natural brown smokey, minimal eye makeup`
