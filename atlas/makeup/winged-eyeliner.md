# 定义 Definition

**上挑眼线**指眼线在眼尾向外、向上**明显拉长并收成尖角**的画法。在视觉系中，
眼线不是"强调眼睛轮廓"的辅助，而是**重构眼形**的主要工具——
它把眼睛的形状"改写"成更锐利、更长、更危险的形态。

配合白妆，一根黑色上挑眼线就能在几乎无色的脸上形成最强对比，
这是视觉系最经济也最有效的辨识符号。

# 视觉特征 Visual Cues

- 眼尾**明显上扬**，拉长长度可远超自然眼尾
- 线条**锐利、边界清晰**，通常较粗（粗黑是常见做法）
- 常与**下眼睑描画**配合，形成包围式或下三角区强调
- 黑色为主；也可用深红、深紫、或 Oshare-kei 的亮彩色
- 眼头可加白色/珠光提亮，进一步拉长眼形

# 变体 Variants

- **经典猫眼**：中等粗细，上扬适中
- **极端拉长**：线条延伸到太阳穴附近，最戏剧化
- **包围式**：上下眼线连成完整轮廓，强化"非人"感
- **彩色上挑**：粉/蓝/紫眼线，属 [[visual-kei-oshare-kei|Oshare-kei]]
- **下三角强调**：重点画下眼尾三角区，制造阴郁

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 日常猫眼线 | 日常追求"修饰"；视觉系追求"改写眼形"，长度与角度都更极端 |
| 埃及式眼线 | 结构与文化脉络不同；视觉系眼线是摇滚舞台造型 |
| 单纯"眼妆浓" | 视觉系的特征是**结构性的上扬与拉长**，不只是浓度 |

# 生成提示 / 常见失败

- 易失败点：模型倾向画"自然的细眼线"。需强调 **dramatic, elongated, thick, sharp flick**
- 双眼**不对称度**要明确指定（若追求 Kote-kei 可轻微不对称）
- 与"遮眼刘海"同时使用时，需明确**哪只眼露出**，否则模型可能两边都画或都遮
- 负向词建议加：`subtle natural eyeliner, thin minimal makeup, no makeup look`
