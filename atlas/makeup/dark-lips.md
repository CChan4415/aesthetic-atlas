# 定义 Definition

**暗色唇**指使用明显深于自然唇色的唇妆：黑、暗红、酒红、紫黑、深棕。
在视觉系的妆容结构里，暗色唇承担的是**"第二对比点"**的角色——

白妆（最亮）→ 深色眼妆（第一暗区）→ 暗色唇（第二暗区）。
三点形成节奏，面部才"完整"。缺少暗色唇时，一张白脸配重眼妆会显得失衡。

# 视觉特征 Visual Cues

- 唇色**明显深于自然**，与白妆形成强对比
- 常见质地：**哑光**（最戏剧化）、丝绒、或高光泽漆面
- 可做**边缘清晰**（精确画出的唇形）或**模糊晕染**（病态感）
- 颜色：纯黑、暗红、酒红、梅子紫、深棕、灰紫
- 男性角色常用**接近无色的苍白唇**作为相反方案（取其"失血感"）

# 变体 Variants

- **纯黑**：最极端，哑光黑最"非人"
- **暗红/酒红**：最经典，华美
- **紫黑/梅子**：冷调，偏 Angura
- **模糊边缘**：唇线晕开，病态、"被咬过"感
- **苍白唇**：接近肤色，取"失血"效果（男性造型常用）
- **漆光黑**：高光泽，偏 Kirakira / 哥特

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 深色口红（日常）| 日常深色唇仍追求滋润自然；视觉系追求**对比与戏剧性**，可完全哑光 |
| 冬季梅子色 | 那偏向"时尚色号"；视觉系暗色唇常接近黑，且与眼妆形成同一体系 |
| 忘记画唇 | 苍白唇是**主动选择**，需与整体造形呼应才成立 |

# 生成提示 / 常见失败

- 易失败点：模型偏向"自然粉唇"。必须明确 **black / dark crimson / matte**
- 若装饰有面纱或遮挡嘴部，需注意可见性
- 与"白妆"配合时，避免模型自动"提亮"唇色以追求好看
- 负向词建议加：`pink lips, nude natural lips, glossy pink lip gloss`
