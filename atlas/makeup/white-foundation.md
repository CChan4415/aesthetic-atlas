# 定义 Definition

**白妆**指使用远白于自然肤色的粉底，把面部处理成**接近石膏、面具、人偶**的质感。
关键在"**刻意**"二字——它必须让人一眼看出这不是自然肤色，而是**化了妆的脸**。

白妆是视觉系妆容的地基。它的功能不是"变好看"，而是：
1. **抹平个体特征**，让脸成为可承载任何妆容的画布
2. **制造非人感/非日常感**，立刻把人物从现实中抽离
3. **提供极致对比**，让黑色眼线、暗色唇、彩色眼影的效果最大化

# 视觉特征 Visual Cues

- 肤色**明显白于自然**，常接近瓷白、象牙白、甚至石膏白
- 覆盖度高、粉感/哑光质感明显（不是水光肌）
- 与颈部、手部形成可见的**色差边界**（这是特征，不是缺陷）
- 面部立体感被削弱，五官靠彩妆重新"画"出来
- 可保留眼部与颧骨的一点血色，避免完全死白

# 变体 Variants

- **瓷白系**：干净均匀的白，最经典
- **石膏系**：完全哑光、无血色，最"非人"
- **透白系**：保留一点自然血色，柔和版本（更易被大众接受）
- **局部白**：只处理面部中心，边缘自然过渡

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 自然白皙皮肤 | 白妆必须**看得出是妆**——有粉感、有色差边界、立体感被削弱 |
| 艺伎白妆（歌舞伎）| 歌舞伎有严格规范与程式化画法；视觉系白妆是自由的、当代的再诠释 |
| 过曝/打光过白 | 那是技术失误；白妆是**化妆决策**，其余部分曝光应正常 |

# 生成提示 / 常见失败

- 易失败点：模型容易"修正"成健康自然肤色。必须强调 **extreme, kabuki-like, mask-like, deliberately unnatural**
- 与"plastic skin"负向词冲突：**若要白妆，应从负向词中移除 `plastic skin` / `doll-like`**，否则模型会抗拒
- 建议同时描述**颈部色差**，可显著提升"这是妆"的可信度
- 负向词建议加：`natural skin tone, tanned skin, healthy glow, sun-kissed`
