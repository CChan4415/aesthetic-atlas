# 定义 Definition

**泪袋妆 / 下眼睑强调**指把妆容重点放在**下眼睑、眼下三角区**的做法。
常规美妆用遮瑕"消除"眼下阴影，视觉系反过来——**主动加深、加红、加亮**这一区域。

它制造的效果是"哭过"、"疲惫"、"病态"或"脆弱"，
与白妆配合时尤其强烈：一张惨白的脸上，眼下泛出红晕或深色，
瞬间把气质从"冷漠"推向"不安"。

# 视觉特征 Visual Cues

- **下眼线**：沿下睫毛根部描画，可延伸至眼尾三角区
- **眼下红晕**：用暗红、玫红、酒红在眼下晕染，模拟充血或哭过
- **泪袋提亮**：用珠光/白色强调眼下凸起，制造"水光"感
- **眼下深色**：黑、灰、紫压暗，制造凹陷与疲惫
- 与上眼妆连成包围式轮廓时可制造"非人"感

# 变体 Variants

- **红晕系**：眼下泛红，像哭过（最有情绪）
- **深色系**：眼下压暗，疲惫/病态
- **提亮系**：泪袋珠光提亮，偏可爱（日系常见）
- **泪痕系**：明显的流痕线条，极端戏剧化
- **包围系**：上下眼妆连成完整轮廓

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 日常"遮黑眼圈" | 目的完全相反：那是消除，这是**强调** |
| 日系"泪袋妆"（可爱版）| 那是提亮追求甜美；本元素的完整范围包含**红晕与深色**的病态方向 |
| 真实红眼（充血）| 那是生理状态；妆容是有设计的色彩与位置控制 |

# 生成提示 / 常见失败

- 易失败点：模型倾向"修饰"眼下，把红晕当瑕疵清理掉。需强调 `red rimmed, intentionally reddened, smudged`
- 与"白妆"配合时，红晕容易被生成成"皮肤过敏"——建议明确部位（under the eyes, lower lash line）
- 负向词建议加：`concealed under-eye, smooth flawless under-eye, no redness`
