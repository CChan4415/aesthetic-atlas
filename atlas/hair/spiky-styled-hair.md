# 定义 Definition

**尖刺立发**指把头发处理成**一根根独立、有明确方向、向上或向外放射的尖刺状结构**的发型。
它不是"头发自然竖起来"，而是**用大量发蜡、发胶、定型喷雾把发束硬化成雕塑**的结果。

这是 Kote-kei 视觉系的标志性符号，也是整套造型里最"非日常"的部分——
它明确宣告："这不是生活，这是舞台。"

# 视觉特征 Visual Cues

- 发束被**分组、加硬、拉出尖锐末端**，边界清晰、互不黏连
- 方向性强：可全部向上、呈放射状、或向前/向后统一指向
- 通常搭配**高对比发色**（黑发为底，或全银/白）
- 结构不对称是常见做法（一侧竖高、一侧压低）
- 定型感可见——**"看得出被处理过"是重点**，不是追求自然

# 变体 Variants

- **放射系**：全方位向外刺出，体积最大
- **向上系**：全部向上，纵向拉长脸型
- **前刺系**：集中向前，有攻击性
- **局部系**：只处理顶部或头顶一区，侧后保留长度
- **银白尖刺**：银白发色 + 尖刺，最"冷"

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 朋克刺头（spiky punk）| 朋克强调叛逆与随机；Kote-kei 尖刺追求**对称/有构图的雕塑感** |
| 自然蓬松发 | 关键差异是"看得出被定型处理"，蓬松是修饰，尖刺是结构 |
| 动漫角色发型 | 现实拍摄中需用大量产品；生成时若不写 "heavy styling product" 容易变成软塌头发 |

# 生成提示 / 常见失败

- 易失败点：模型容易生成"稍微翘起的日常发型"。**必须强调 extremely / sculptural / rigid / heavy product**
- 若需保持年代感，配 `2000s J-rock`、`visual kei` 等风格锚点
- 负向词建议加：`soft natural hair, flat limp hair, casual hairstyle`
