# 定义 Definition

**遮眼刘海**指刘海留长到**覆盖一只或双眼**的发型。它牺牲了"看清脸"的清晰度，
换取极强的**神秘感与疏离感**——观众看不到完整的面孔，因此只能感到气质的压迫。

在视觉系中，遮眼是**表演性的**：它让你无法确定对方是否在看你，
从而制造一种"被凝视"或"被无视"的张力。

# 视觉特征 Visual Cues

- 刘海长度**明显超过眉毛，直达或超过眼睛**
- 常见**不对称**：只遮一侧（另一侧脸完全露出），强化反差
- 发丝可以是**薄纱感半透**（隐约见眼）或**厚重实心**（完全遮住）
- 发质通常顺直、有重量感、贴合面部轮廓
- 黑发最常见；银白或深色系也可

# 变体 Variants

- **单侧遮眼**：只遮一只，另一只眼完全露出（最常用，兼顾神秘与可读性）
- **双侧遮眼**：双眼半遮，几乎不可见，最极端
- **薄纱半透**：发丝稀疏，能隐约看见眼睛（更柔和）
- **厚重实心**：完全遮蔽，最强压迫感
- **搭配长发**：遮眼刘海 + 及肩/及腰长直发

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 普通刘海 | 普通刘海到眉毛；遮眼刘海必须**明显过眼** |
| 中性发型（curtain bangs）| 中分帘式刘海露出额头与双眼，气质是柔和；遮眼刘海气质是遮蔽 |

# 生成提示 / 常见失败

- 易失败点：模型倾向"把眼睛画出来"，导致刘海变短。**必须强调 covering / obscuring / hiding one eye**
- 建议明确指定"哪只眼被遮"以保持系列一致性
- 若需保留面部辨识度，选"单侧遮眼"
- 负向词建议加：`both eyes fully visible, short bangs, forehead exposed`
