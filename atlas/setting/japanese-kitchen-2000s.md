# 定义 Definition

2000 年代日本单身公寓（1K / ワンルーム）的窄长小厨房：进门即厨房（玄関旁），
单侧台面、双口煤气灶、小型冰箱、电饭煲、墙上挂杆、小窗户。
是日式日常系动画与游戏中最高频的"晨起"场景。

# 视觉特征 Visual Cues

- **布局**：窄长单边台面（I 型），宽不足 1.5m
- **灶台**：双口煤气灶（ガスコンロ），银色金属面
- **电器**：小型白色冰箱、电饭煲、电热水壶、烤面包机
- **台面**：木色或米色防火板，堆碗碟与调味品
- **窗户**：小窗，晨光斜射
- **细节**：挂杆上的毛巾、磁铁贴、账单、便利店塑料袋
