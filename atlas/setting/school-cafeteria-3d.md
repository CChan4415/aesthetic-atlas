# 定义 Definition

**学校食堂 · 3D** 是 2000s 校园同人 CG 与低多边形游戏中的典型"午餐场景"：
- 长条木桌（多人共坐）
- JK 学生群体用餐（有主角、有配角、有背景人物）
- 午后阳光从大窗斜射入（暖黄、长阴影）
- 整体氛围温暖但带孤独感（主角可能独自一人）

> **核心氛围**：**群体中的孤独**——食堂是社交场所，但主角常是观察者或独自用餐者。

# 视觉特征 Visual Cues

- **桌子**：长条形木桌（实木或贴皮）、可坐 6–10 人
- **椅子**：简单木质或金属框架椅
- **餐具**：托盘、筷子、便当盒、饮料瓶
- **窗户**：大窗户（占墙面 50%+）、窗外可见树木或建筑
- **光线**：午后阳光（15:00–17:00）、暖黄、长阴影、桌面有光斑
- **人物**：5–15 个 JK 学生，主角可能独自一人或与他人相对而坐
- **背景**：可能可见打饭窗口、菜单看板、自动售货机

# 适用风格 Applies To

- **必需**：[[retro-game-cg|Retro Game CG]] 的 Low-Poly JK Slice-of-Life（午餐场景）
- **不适用**：[[y2k|Y2K]]（那是真人摄影）、[[visual-kei|Visual Kei]]（那是舞台场景）

# 搭配建议 Pairs With

- 介质：[[low-poly-3d-render|低多边形 3D 渲染]] 或 [[ps2-fmv-grade|PS2 FMV]]（更精细版）
- 主体：[[lowpoly-jk-character|低多边形 JK 角色]]（多人）
- 镜头：[[third-person-game-camera|第三人称游戏视角]]（从主角背后看食堂全景）
- 光影：[[golden-hour-backlight|黄金时刻逆光]]（午后阳光）
- 情绪：孤独、怀旧、青春

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| **当代动漫食堂场景** | 那是 2D 动漫或精致 3D；本元素是低多边形 |
| **真人日剧食堂** | 那是真人摄影；本元素是 3D 渲染 |
| **咖啡馆** | 咖啡馆更小更私密；食堂是公共大空间 |

# 生成提示 / 常见失败

- **人物不够**：`multiple students in the background, some sitting in groups, protagonist sitting alone`
- **光线不对**：`afternoon golden sunlight streaming through large windows, long shadows`
- **桌子太空**：`trays with bento boxes, chopsticks, drink bottles on the table`
- **氛围太欢快**：主角应**独自一人或凝视他人**，`protagonist eating alone, observing others`
