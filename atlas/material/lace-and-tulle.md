# 定义 Definition

**蕾丝与网纱**是视觉系（尤其 [[visual-kei-angura|Angura]]）的材质基石。
它们的共同特征是**半透明**——覆盖在皮肤或其它面料之上，让下层隐约可见。
这种"遮挡但不遮蔽"的特性，正是视觉系想要的效果：**神秘、层次、脆弱而繁复**。

蕾丝提供**图案与细节**（花纹、镂空、边缘），网纱提供**体积与朦胧**（蓬起、垂坠、雾化）。

# 视觉特征 Visual Cues

- **半透明**：能看到下层皮肤或面料
- **图案性**：蕾丝的镂空花纹、花边、网眼结构
- **边缘装饰**：荷叶边、齿状边、卷草纹
- 颜色：黑为主，也见白、暗红、紫、酒红
- 常**多层叠加**，制造深度与复杂度
- 垂坠感强，随风/动作轻轻浮动

# 变体 Variants

- **黑蕾丝**：最经典，哥特感
- **白蕾丝**：纯洁感，常用于人偶系
- **暗红蕾丝**：华美危险，吸血鬼系
- **硬网纱（tulle）**：有支撑力，用于蓬裙与头纱
- **软网纱（mesh）**：贴合身体，用于内搭与袖套
- **蕾丝拼接**：只作局部装饰（袖口、领口、下摆）

# 适用风格 Applies To

- [[visual-kei-angura|Angura]]（核心）、[[visual-kei-kote-kei|Kote-kei]]（细节）、[[visual-kei-kirakira|Kirakira]]

  Y2K 的网纱用于"性感透视"，视觉系的网纱用于"华丽遮蔽"

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| Y2K 网纱 | Y2K 强调身体线条与性感；视觉系强调华丽层次与遮蔽 |
| 婚纱蕾丝 | 语境与文化符码不同；视觉系蕾丝是暗色与戏剧化的 |
| 单纯"衣服有花纹" | 蕾丝的核心是**镂空 + 半透**，不是印花 |

# 生成提示 / 常见失败

- 易失败点：模型容易把蕾丝画成**印花图案**而非镂空结构。需强调 **intricate lace detailing, sheer, see-through, layered**
- 蕾丝细节在低分辨率下会糊成噪点——若需细节，应提高分辨率或拉近景别
- 与"VHS 颗粒"等强质感同时使用时，蕾丝细节会损失，需权衡
