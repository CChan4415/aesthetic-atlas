# 定义 Definition

**缎面（satin）** 与 **天鹅绒（velvet）** 是一对互补的高级材质：

- **缎面**：正面光滑、**高反光、有流动感**，会随角度和动作产生亮暗变化
- **天鹅绒**：表面有细密绒毛、**强吸光、颜色极深**，看起来"厚重而柔软"

两者经常组合使用，因为它们在光下形成完美对比：缎面**抓光**，天鹅绒**吃光**。
这正好对应视觉系想要的"华美（缎）与阴郁（绒）"并存。

# 视觉特征 Visual Cues

## 缎面
- 高光泽、反光带明显，会随动作"流动"
- 垂坠感强，褶皱处形成亮线
- 常见颜色：黑、暗红、酒红、紫、白、金
- 常见用途：衬衫、长裙、内衬、缎带、翻领

## 天鹅绒
- 表面哑光、吸光，颜色看起来**格外深**
- 触感/视觉上有绒毛质感，边缘会有柔和的**光泽描边**（vintage velvet 的典型特征）
- 常见颜色：黑、深红、墨绿、深紫、宝蓝
- 常见用途：外套、长裙、束腰、西装

# 变体 Variants

- **黑缎 + 黑绒**：全黑但层次分明（最高级用法）
- **暗红缎 / 酒红绒**：华美危险，偏 Angura / 吸血鬼系
- **紫绒**：神秘、贵族
- **墨绿绒**：异质、古典
- **金缎**：偏 Kirakira

# 搭配建议 Pairs With

- 材质：[[lace-and-tulle|蕾丝与网纱]]（缎/绒 + 蕾丝是经典三层）
- 材质：[[leather-and-hardware|皮革与金属件]]
- 光影：**侧光或逆光**是必需品——缎面的光泽与绒的描边都依赖方向性光
- 动态：缎面在动作中的流光极适合视频（缓慢转身、布料拂动）

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 丝绸（silk）| silk 是纤维，satin 是织法；生成时用 satin 更准确表达"光泽" |
| 亮面涤纶 | 廉价替代品会显得"塑料"，需靠光影与场景消解 |
| 普通暗色布料 | 天鹅绒的特征是**吸光 + 边缘光泽**，不是单纯"深色" |

# 生成提示 / 常见失败

- 易失败点：模型容易把缎面画成**平整的亮色块**，失去"流动光泽"。需强调 **liquid sheen, folds, drape, light-catching**
- 天鹅绒容易生成成"毛毯"质感——强调 **luxurious, soft nap, deep rich color** 而非 furry
- 全黑造型（黑缎+黑绒+黑蕾丝）容易糊成一团，**必须靠光影分开层次**，建议明确光源方向
