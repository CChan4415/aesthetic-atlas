# 定义 Definition

**皮革与金属件**指皮革（光面皮、漆皮、麂皮）与金属五金（扣具、铆钉、链条、拉链、D 环）
的组合使用。它们为视觉系造型提供**硬度**——与蕾丝的柔软脆弱形成对比，
让整体不流于"只是一堆漂亮的布料"。

金属件的功能不只是装饰，更是**视觉节奏点**：在深色面料上，金属反光是
唯一的亮点，引导视线移动。

# 视觉特征 Visual Cues

- **皮革**：光面皮（高反光）、漆皮（极亮）、麂皮（哑光绒面）
- **金属**：银/铬（冷）、暗金/氧化银（复古）、黑镍（低调）
- 五金件形态：铆钉、尖刺、链条、扣环、拉链、安全别针
- 常见于：束腰、皮质外套、手套、颈环（choker）、腰带、靴
- 黑色为主，金属色作点缀

# 变体 Variants

- **光面皮**：经典，中高反光
- **漆皮**：极高反光，最"非日常"，偏 Kirakira
- **麂皮**：哑光，柔和版本
- **铆钉系**：密集尖刺，朋克感（偏 Grunge）
- **链条系**：垂坠链条，华丽暗黑
- **束腰/绑带**：功能性金属件，强调躯干线条

# 搭配建议 Pairs With

- 材质：[[lace-and-tulle|蕾丝与网纱]]（硬软对比是核心手法）
- 材质：[[satin-velvet|缎面与天鹅绒]]
- 服装：[[black-tailored-suit|黑色西装]]
- 光影：强光让金属产生**高光点**；硬光让皮革产生明确反光带
- 质感：高对比、保留高光细节

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| PVC / 乳胶 | PVC 是塑料涂层，反光更均匀、更"湿"；皮革有纹理与自然折痕 |
| 金属色面料 | 那是"看起来像金属的布"；金属件是**实体五金**，有厚度与投影 |
| 单纯穿黑皮衣 | 视觉系的用法是**皮革 + 金属 + 蕾丝/垂坠**的多材质组合，而非单件皮衣 |

# 生成提示 / 常见失败

- 易失败点：模型容易把金属扣件画成**模糊色块**或位置错乱。需明确 **distinct metal buckles, studs, chains**
- 漆皮的高反光易与"塑料感"负向词冲突——使用时需从负向词中移除相关项
- 建议指定金属**颜色**（silver vs gold vs black nickel），避免随机
