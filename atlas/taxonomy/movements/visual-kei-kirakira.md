# 定义 Definition

**Kirakira-kei（キラキラ系，"闪闪发亮系"）** 是视觉系中把**"闪耀"推到极致**的分支。
"キラキラ" 是日语拟态词，形容闪烁发光的样子。这一支的逻辑很简单：
**在舞台上，光就是武器**——所以它把一切能反光的材质都穿在身上。

Kirakira 与 Y2K 的 McBling（炫富美学）在材质上有亲缘，但气质不同：
McBling 强调"贵"（logo、皮草、珠宝），Kirakira 强调"亮"（闪光、舞台感、表演性）。

# 视觉特征 Visual Cues

## 色彩
- **金属色为骨架**：银、亮金、铬、玫瑰金
- 底色黑或白，让金属色跳出来
- 可混彩色宝石色：宝蓝、祖母绿、紫水晶
- 允许全息/Holographic 的彩虹反光

## 材质（这是分支的核心）
- **亮片（sequins）**、水钻、施华洛世奇水晶
- **金属光泽面料**：金葱布、镭射、液态铬、箔面
- 羽毛、流苏、珠串
- 一切**会随光线变化**的表面

## 妆容
- 眼部使用**亮片、水钻、金属色眼影**
- 面部可贴水钻（眼下、颧骨、眉骨）
- 唇：金属光泽或高亮唇彩
- 底妆追求**光泽感**（不是哑光）

## 发型
- 有光泽感的发，可喷金属色临时染
- 常配闪亮发饰、水钻发夹、金属头饰
- 造型强度中高，但重点在"闪"而非"刺"

## 服装
- 金属色西装、亮片外套、镭射材质
- 大量装饰：珠绣、亮片刺绣、金属链条
- 舞台感强，接近"演出服"而非日常服

# 变体 Variants

- **银系**：冷银 + 水晶，最"未来"
- **金系**：亮金 + 黑，最"炫耀"
- **全息系**：镭射彩虹反光，偏 Y2K 未来感
- **舞台剧系**：羽毛 + 流苏 + 珠绣，最繁复

# 搭配建议 Pairs With

- 光影：**点光源与闪光**是必需品——没有强光就拍不出闪耀
- 质感：高光溢出、星芒、镜头光晕（halation）
- 动态：旋转、甩头、转身——让反光流动起来

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| McBling（Y2K）| McBling 用"贵"表达地位（logo/皮草/珠宝）；Kirakira 用"亮"表达舞台感 |
| 单纯穿亮片 | Kirakira 需要整体妆造与**灯光配合**，否则只是"衣服很闪" |
| Disco / 70s glam | 时代与音乐脉络不同；Kirakira 是日系视觉系的当代分支 |
