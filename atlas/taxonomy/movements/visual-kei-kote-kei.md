# 定义 Definition

**Kote-kei（コテ系，"定型系"）** 是视觉系中最经典、最具辨识度的分支。"コテ" 原指发蜡/定型剂，
引申为"把造型做到极致定型"的做法——这个名字本身就说明：**这个分支的核心是"结构感"**。

Kote-kei 拒绝一切柔软与随意。它要的是**锐利的轮廓线、绝对的黑色、和一张近乎面具的白脸**。
它是最容易被一眼识别的视觉系形象，也是最"图腾化"的一支。

# 视觉特征 Visual Cues

## 色彩
- **纯黑为绝对主色**，黑白强对比，银/铬作为唯一点缀
- 几乎不用彩色（这是与 Oshare-kei 的根本分野）
- 允许极少量的血红或深紫作为点睛

## 妆容
- **极端白皙底妆**（"白妆"）——不是自然白，是刻意失真的石膏感/面具感
- **重眼妆**：上挑的粗黑眼线、眼尾拉长、下眼睑重描（制造阴郁感）
- 眼影：黑、灰、深紫烟熏，或极简到只有眼线
- 唇：黑、暗红、或接近无色的苍白唇；男性常全无血色感
- 眉毛：细、挑、可完全压平或刻意画细

## 发型
- **尖刺立发**是最强符号——用大量定型剂做出放射状、有方向的尖刺
- 或**长直发 + 遮眼刘海**（一侧眼睛完全被发丝覆盖）
- 发色以黑为主，可有银白、灰、或单色挑染
- 结构感：不对称、有明确方向性、体积夸张

## 服装
- **黑色西装**（修身、长下摆、或燕尾式）为绝对主力
- 黑色衬衫、立领、或高领
- 蕾丝细节、绑带、金属扣、皮质元素
- 长靴、尖锐鞋型

## 气质
- 冷峻、锐利、攻击性、威压感
- 与"甜美"完全绝缘——这是家族里的暗面一极

# 变体 Variants

- **经典 Kote**：黑西装 + 尖刺发 + 白妆（1990s 末–2000s 初标准形象）
- **暗黑 Kote**：加入皮革、铆钉、更长下摆，靠近哥特
- **现代 Kote**：保留黑白骨架，发型更短更利落，靠合成器时代气质

# 适用风格 Applies To

- 母风格：[[visual-kei|Visual Kei]]
- 易与 [[y2k-cyber-metal|Cyber Metal]] 混搭（冷黑 + 金属质感），但区别在于：
  **Cyber Metal 是"未来科技"，Kote-kei 是"戏剧角色"**——前者冷在材质，后者冷在表演性

# 搭配建议 Pairs With

- 光影：强单点光 + 硬阴影（拒绝柔光、拒绝平光）
- 质感：高对比、轻微去饱和、可加轻颗粒
- 场景：空旷剧场、黑背景、老旧洋馆、舞台、雨夜街道

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| 哥特（Gothic）| 哥特是西方脉络、有宗教与维多利亚符码；Kote-kei 是日系摇滚舞台造型，核心是"定型感"与锐利线条 |
| Emo / 场景少年 | Emo 强调情绪化与日常感，Kote-kei 强调非日常的舞台化 |
| 单纯"穿黑衣服" | Kote-kei 必须有妆容与发型的强结构，只有黑衣不构成 Kote-kei |
