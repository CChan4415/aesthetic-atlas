# 定义 Definition

**McBling** 指 2000s 中期由嘻哈文化与名媛（socialite）文化共同驱动的**炫耀型奢华美学**。
名字来自 "Mc"（麦当劳式的量产大众化）+ "Bling"（珠宝闪光声），
本身就是自嘲式的命名：**把奢侈品穿成快消品，把炫富当成一种表演**。

与 [[visual-kei-kirakira|Kirakira]] 的关键区别：
- Kirakira 用"亮"表达**舞台感**（金属、亮片、全息）
- McBling 用"贵"表达**地位**（粉钻、皮草、logo、镀铬塑料）

McBling 的迷人之处在于它**不装高级**——它是过度、俗艳、理直气壮的。
这种"反面品味"正是 Y2K 亚文化最有趣的部分。

# 视觉特征 Visual Cues

## 色彩
- **粉 + 白 + 银** 是最经典组合（Paris Hilton 式）
- 或 **金 + 棕 + 豹纹**（Hip-hop 名媛系）
- 高饱和、高亮度，拒绝克制
- 可全息/镭射反光

## 材质
- **水钻与钻石**（含大量仿钻、粉钻）
- **皮草**（真/仿，粉色或白色最典型）
- **天鹅绒运动套装**（Juicy Couture 式）
- 镀铬、镭射、金属箔、亮面漆皮
- 亮片、珠绣

## 配件（这一支的重灾区）
- **超大墨镜**（尤其茶色渐变、水钻镶边）
- **大号 Logo 手袋**（越显眼越好）
- **堆叠的珠宝**：大戒指、粗链、耳环
- **棒球帽**（镶钻或亮色）
- 腰带（大 logo 扣）、肚链
- 手机（翻盖/镶钻外壳）
- 宠物（吉娃娃，作为配饰出现）

## 妆容
- **闪光/亮粉**感底妆，古铜色修容
- 眼妆：亮片、浅色珠光
- 唇：高光泽唇彩（粉、蜜桃、透明）
- 指甲：长、方、镶钻（法式或彩色）
- 可贴身体亮片

## 发型
- 长直发、或大波浪
- 高马尾、发髻（配亮色发圈）
- 发色：金、棕、黑，可有粉色挑染
- 可用大水钻发夹

# 变体 Variants

- **粉白名媛系**：Paris Hilton 式，粉/白/银 + 皮草 + 大墨镜
- **Hip-hop 金系**：金/棕 + 豹纹 + 粗链 + logo 包
- **镀铬塑料系**：镀铬配件 + 镭射材质，偏未来炫耀
- **运动套装系**：丝绒运动套装 + 棒球帽 + 大水钻耳环
