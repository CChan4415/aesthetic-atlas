# 定义 Definition

**Cyber Goth** 是 Y2K 时代的亚文化分支，把**哥特的暗黑**、**工业音乐的机械感**、
**锐舞文化的荧光**与**千禧科技想象**混在一起。它和 [[y2k-cyber-metal|Cyber Metal]] 是近亲，
但精神气质不同：

- **Cyber Metal** 偏"高级时尚的金属未来主义"——干净、冷艳、镀铬、像广告大片
- **Cyber Goth** 偏"地下亚文化"——更脏、更硬、更有攻击性，有护目镜、防毒面具、
  气管、义体、军用件等**工业与末日符号**

如果你要的是"黑客帝国 + 地下俱乐部"的感觉，而不是"银色时装大片"，就应该走这支。

# 视觉特征 Visual Cues

## 色彩
- **接近全黑**，配深灰、暗绿（军用）、电蓝或霓虹绿作**极少量**点缀
- 与 Cyber Metal 的区别：**不用大面积亮银**，金属更多是哑光黑镍或枪灰
- 可出现荧光色，但作为"信号灯"式的点缀，不是主色

## 材质
- **PVC、乳胶、漆皮**（高反光、贴合身体）
- **哑光黑皮革 + 工业五金**
- 网格面料（网眼、渔网、冲孔）
- 橡胶、软管、绑带、扎带

## 服装与配件
- 紧身 PVC 上衣、束腰、工装裤、军靴
- **护目镜（goggles）** 是最强符号——可戴在眼上或推到额头
- 防毒面具、口罩、气管
- 大量绑带、扣具、D 环、链条
- 手套（尤指长皮手套）

## 妆容
- 眼妆深色但**更"脏"更锐利**，可加几何线条
- 可做义体感：金属色块、仿电路线条、面部金属贴片
- 唇色黑或暗
- 底妆可白可自然（不像视觉系必须白妆）

## 发型
- 直发、脏辫（dreadlocks）、剃边（undercut）、双马尾
- 发色黑为主，可有荧光挑染
- 可用工业感发饰、绑带、软管

# 变体 Variants

- **俱乐部系**：偏锐舞、荧光点缀、护目镜与网格
- **工业系**：偏机械、工装、军绿、软管与面具
- **义体系**：面部/身体金属件、仿电路、义肢暗示
- **末日系**：破旧、临时改造、废土感

# 适用风格 Applies To

- 母风格：[[y2k|Y2K]]
- 近亲：[[y2k-cyber-metal|Cyber Metal]]（更干净高级）、[[y2k-grunge-glam|Grunge Glam]]（更颓废）
- 与 Visual Kei 的 [[visual-kei-kote-kei|Kote-kei]] 可混搭（冷黑 + 攻击性），
  但区别：**Kote-kei 冷在戏剧妆造，Cyber Goth 冷在工业装备**

# 搭配建议 Pairs With

- 材质：[[pvc-vinyl|pvc-vinyl]]、[[leather-and-hardware|皮革与金属件]]
- 光影：**硬光 + 强闪光**（直闪或单点硬光），追求"地下俱乐部实拍"感
- 质感：高对比、深黑、可加轻颗粒与色偏
- 动态：机械式动作、快速甩头、频闪

# 易混 / 反例 Not To Confuse

| 容易混淆 | 区别 |
|---|---|
| Cyber Metal | Cyber Metal 明亮、镀铬、时尚大片感；Cyber Goth 暗黑、工业、地下感 |
| 哥特（传统）| 传统哥特有维多利亚与宗教符码、蕾丝与长裙；Cyber Goth 是科技与工业符码 |
| 赛博朋克 | 赛博朋克是更广的科幻叙事（含街景、霓虹都市）；Cyber Goth 是具体的穿着亚文化 |
| 单纯穿黑 | 需要**工业装备符号**（护目镜/绑带/面具/PVC）才成立 |
