# 定义 Definition

**Y2K（Year 2000）** 指约 **1997–2006** 千禧年之交的视觉与时尚风格。它建立在对新世纪与新技术
（互联网、翻盖手机、太空探索、数字未来）的**乐观想象**之上，混合了太空时代复古未来主义、街头嘻哈、
日韩偶像工业与高端时装实验，是一种"对未来的怀旧"。

# 时代背景 Context

- 技术：拨号上网、CRT 显示器、翻盖/直板手机、CD/MD、早期 3D 游戏与 CG、电子宠物。
- 流行：欧美 Teen Pop 爆发（Britney、Christina、*NSYNC），日韩偶像黄金期（早安少女组、滨崎步、
  安室奈美惠、S.E.S.），嘻哈进入主流。
- 时装：低腰裤、Baby Tee、丝绒运动套装、金属色与亮片、夸张水钻配饰、徽标狂热（logomania）。
