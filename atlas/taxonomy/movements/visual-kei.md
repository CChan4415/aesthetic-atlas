# 定义 Definition

**视觉系（Visual Kei / ヴィジュアル系）** 是 1980 年代中期起源于日本地下摇滚场景的美学运动。
其核心主张是：**音乐表演的视觉呈现与音乐本身同等重要**。它并非单一风格，而是一个
**风格家族（style family）**——同一面旗帜下并存着走向截然相反的分支，从冷峻黑衣到糖果色甜美。

> 关键认知：视觉系**不是 Y2K 的子风格**。它始于 1980s 中（X Japan、D'erlanger、Color 等
> 地下乐队），在 1990s 末–2000s 初达到商业巅峰，与 Y2K 在时间上重叠、在精神上互相渗透
> （都是"世纪末的华丽与不安"），但语汇体系独立。故本库将其建为**与 Y2K 平级的独立风格运动**。

# 视觉语法：家族共性 Visual Grammar

无论哪个分支，视觉系都遵循以下**共通语法**——这是它的辨识度来源：

1. **面部即画布**：妆容是核心而非辅助。极端白皙底妆、强调眼部的重彩、唇部强对比。
2. **非日常发型**：结构感、体积感、方向感极强的发型，几乎不做"自然日常"发。
3. **雌雄莫辨（Androgyny）**：男性化的轮廓 + 女性化的妆饰，或反之，性别表达刻意模糊。
4. **造型即叙事**：每套造型像一次角色扮演（吸血鬼、贵族、人偶、军人、花魁）。
5. **层级与垂坠**：大量叠穿、垂坠面料、绑带、金属件。
6. **高对比光影**：强单点光、深阴影，拒绝平光的生活感。
7. **黑色为骨**：几乎所有分支都以黑为骨架色，再叠加各自的主题色。
